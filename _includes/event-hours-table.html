{% comment %} Event hours table — maker-facing schedule of check-in, load-in, show hours and load-out, used on /badge/. Replaces the old run of one-line paragraphs: on desktop this is a two-column table (time / what's happening) banded by day; under 600px every cell stacks so each entry reads as a small card with the time on top. Styles live in assets/css/mfo-redesign.css §16 (.mf-hours-*). Day dates come from site.data.settings.event_dates so they follow the year automatically. There is no Thursday key in settings, so Thursday is derived from edu_day by epoch math: back one day, then forward 12 hours. The dates parse as UTC midnight but the date filter prints them in site.timezone (America/New_York), so without that midday anchor the result lands on the previous evening and the label comes out a day early. Rows marked .is-show are public show hours (the gates-open-to-the-public times), tinted so makers can find them at a glance. {% endcomment %} {% assign ev = site.data.settings.event_dates %} {% assign thu_date = ev.edu_day | date: "%s" | minus: 86400 | plus: 43200 | date: "%b %-d" %}
