{% comment %} Sponsor logo marquee — a single, continuously-scrolling band of sponsor logos, emulating the sponsor strip on makerfaire.com/bay-area. Base (no-JS): pure CSS — the logo set is rendered twice (the second copy is aria-hidden + inert) and the track is animated -50% for a seamless infinite loop. Speed is set per-logo via an inline animation-duration so the band scrolls at a consistent pace regardless of how many sponsors are active. Pauses on hover; collapses to a static wrapped grid under reduced-motion. Progressive enhancement (JS at the bottom): if JS is on and the user hasn't asked for reduced motion, the script disables the CSS animation and drives the scroll itself, adding click/touch drag-to-scrub (grab and pull it back and forth, like the Swiper strip on the Bay Area page). Auto-scroll resumes on release; hovering pauses; a real drag suppresses the sponsor-link click. Styling lives in assets/css/mfo-redesign.css §12 (.mf-sponsor-marquee).
